# GestionEspaces.Web

Frontend React du projet GestionEspaces. Voir le [README racine](../README.md) pour la présentation complète du projet, les instructions d'installation et de démarrage, et les comptes de test.

```bash
npm install
npm run dev
```

L'application démarre sur `http://localhost:5173` et communique avec l'API backend sur `http://localhost:5153` (voir `src/services/api.js`).
